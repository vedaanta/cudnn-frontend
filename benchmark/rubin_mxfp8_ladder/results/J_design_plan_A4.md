# Judge's implementation plan for design A4 (not built; see J_design_panel.md for why)

All work in python/cudnn/sdpa/fwd/kernels/sm107/prefill_d128_mxfp8_ladder.py behind one import-time knob LADDER_A4=1 (requires LADDER_F16EXP=1 LADDER_CORRFAST=1; mutually exclusive with SDOUBLE/PSMEM/PREF/PAGED64/PIPE4); sub-knobs LADDER_A4_PREFETCH=0|1|2 (none / after chunk-b cvt = PREF placement / after chunk-b pack), LADDER_A4_POLL=0|1 (fixed MMA order / event-driven poll), LADDER_A4_HINTWAITS=0|1. Add every knob to bench_ladder._env_from_rung's suffix list and to the kmod dict.

0. Config override (after make_cfg_d128_mxfp8, next to the LADDER_SMREGS replace): CFG = replace(CFG, TILES_Q=1, STAGES_KV=8). CGA_TILE_M becomes 256; make_sdpa_helpers / n_q_supers / LPT decode already run TILES_Q=1 for d256, verify _host's q-super arithmetic. SMEM by _smem_offset_of_ones: sQ 16 + sK 8x8 + sV 8x8 + sO 32 (bf16) + SF slabs (Q 1 | K 4 | P 4 | V 4) + ones 1 + s_alpha 1 + max slab 1 ~= 192 KiB; ones tile at ~190 KiB, under the 256 KiB DESC_VERSION=0 window (the import-time guard recomputes it). Registers unchanged 8x192 + 4x88 + 4x40 = 65536.

1. TMEM map (new KernelTmemLayoutA4, TOTAL_COLS stays 576, is_exclusive):
   Q_OFF=0 (32 cols: 128 fp8 per lane, TS A operand, tmem_advance_A=16 per K64 step) | P_OFF[a]=32, P_OFF[b]=64 (32 each) | SF_Q_OFF=96 (4) | SF_K_OFF=100 (2 slots x 4, slot = kv_tile & 1) | SF_V_OFF=108 (2 x 4) | SF_P_OFF=116 (4) | STATS_OFF=120 (4: max_a, sum_a, max_b, sum_b) | S_OFF[a]=128, S_OFF[b]=256 (128 fp32 each, no P tail) | O_OFF=384 (128) | SIG_OFF=512 (16) => 528 used, 48 spare. Every MMA operand base is 32-aligned (Q 0, P 32/64, S 128/256, O 384), SF tiles 4-aligned as today. _SUM_OFF = O_OFF + TILE_O. Import-time raise if SIG_OFF + 16 > 576.

2. Barriers: bars = make_classic_bars(CFG, s_stages=2) gives mb_bmm1_done[2] and mb_bmm2_ready[4] (index wg*2 + chunk; counts chunk0 = SOFTMAX_PLUS_CORR_TOTAL, chunk1 = SOFTMAX_LANES_TOTAL, LEADER scope -- the single-sub-tile two-slot ring this factory already supports); override like _sd_bars: mb_bmm2_done[2], mb_stat_full[2], mb_stat_empty[2] (per WG). New: s_free[2] (LEADER scope, init SOFTMAX_LANES x CTA_MMA, exactly PREF's sd_s_free), max_ready[2] (CTA-local THREAD producer, init SOFTMAX_LANES, index = publishing WG), mb_q_tmem (LEADER scope, init 2 x CTA_MMA: one elected lane per WG per CTA after the copy), mb_q_empty[1] producer moves from the MMA commit to the same elected lanes (init 2). Named barrier id 8 (256 threads) is reused as the tile-boundary WG0+WG1 sync (the ping-pong is gone); ids 1/2 unchanged. Per-WG phase variables everywhere (MMA: sfree_phase[2], bmm2_ready_phase[2], bmm1 parity per WG; softmax: its own; correction: stat_full/bmm2_done phase per WG): each WG processes KV tiles k with (k - kv_left) & 1 == wg, so under causal the two counts differ by at most one per Q tile and the per-WG counters stay consistent across persistent tiles; the P14-style end-of-tile catch-up flips become per WG.

3. Q -> TMEM once per Q tile (softmax warps, both WGs, after bar 8 at the tile boundary, which also proves every BMM1 of the previous tile retired because each WG waited its own last bmm1_done): wait mb_q_full[0]; thread row r = tid_in_wg loads its 128 B row from the 128B-swizzled sQ[0] (chunk c at byte r*128 + ((c ^ (r & 7)) << 4), 8 x LDS.128); WG-a stores words 0-15 (K 0-63) and WG-b words 16-31 (K 64-127) with tcgen05.st 32x32b.x16 at Q_OFF (+16) -- the P-store layout (4 consecutive K elements per 32-bit column); tcgen05.wait::st; WG-level bar; elected lane arrives mb_q_tmem (leader) and mb_q_empty. MMA: wait q_full -> cp SF_Q (today's SF_Q0 cp) -> wait mb_q_tmem -> prologue BMM1s. BMM1 = mma_ts(bmm1_desc_ts, tmem_raw.subview(Q_OFF), desc_K, tmem_raw.subview(S_OFF[w]), tmem_sf_a=tmem_SF_Q, tmem_sf_b=tmem_SF_K[k & 1]) with bmm1_desc_ts = bmm1_desc (same idesc_qk_bs, k_dim=1, K=64 steps) -- the TS block-scale form today's PV uses.

4. MMA stream (leader warp), per Q tile with kv tiles k in [left, right): prologue: wait stats_read, q_full, cp SF_Q, wait q_tmem; wait k_full(left), cp SF_K[0], BMM1_a(left) -> commit bmm1_done[a] -> arrive k_empty; if right - left >= 2: wait k_full(left+1), cp SF_K[1], BMM1_b(left+1) -> commit bmm1_done[b] -> arrive k_empty. Steady state per period p (k = left + 2p): [wait s_free[a] -> wait k_full(k+2) -> cp SF_K[(k+2)&1] -> BMM1_a(k+2) -> commit bmm1_done[a] -> arrive k_empty] [wait v_full(k-1) -> cp SF_V[(k-1)&1] -> wait bmm2_ready[b*2+0] -> PV_b(k-1) chunk 0 -> wait bmm2_ready[b*2+1] -> PV_b chunk 1 + Sigma (mma_ts_step x2 with A = P_OFF[b], tmem_sf_a = SF_P, tmem_sf_b = SF_V[(k-1)&1]) -> commit bmm2_done[b] -> arrive v_empty(k-1)] [wait s_free[b] -> BMM1_b(k+3) ...] [PV_a(k) ...]. This fixed order is non-blocking for 500 <= T <= 1000 clk per period (s_free precedes the same WG's P by ~500 and the WGs are ~T/2 apart); LADDER_A4_POLL=1 replaces it with a loop over the four parity tests (mbarrier_try_wait_parity, non-blocking) that issues whichever of {BMM1_a, PV_b, BMM1_b, PV_a} is ready, in tile order per WG. Tail: for the last 1-2 tiles consume the dangling s_free arrivals, then the remaining PVs; arrive v_empty; stats_read handshake as today. Per-WG SF slots make every cp land at least one period after that slot's previous reader -- no cp-after-MMA WAR reliance. K/V ring: V(k-1..k+3) pinned (5 of 8 stages) -> 3 stages of TMA prefetch cover (~1200 clk at T=800).

5. Softmax body per WG (new _a4_softmax_kv_body, derived from _pf_softmax_kv_body with the SMEM P stores replaced by the classic tcgen05.st + _ladder_st_sync + arrive): inputs res_a/res_b (this tile's S, prefetched or loaded in the prologue). (a) max words -> rmax (masked LEFT/RIGHT segments: plain loads + apply_mask_chunk + software max, each WG iterating its own kv subsequence of each segment). (b) s_free[w].arrive(leader) -- S_w free. (c) ratchet: unless this is WG-a's first tile of the Q tile, wait max_ready[w'] (parity = this WG's tile count & 1) and m_prev = max_slab[(k-left-1)&1][row] (LDS, acquire via the wait), else m_prev = -inf; update_cond = (m_prev == -inf) | (rmax*scale_log2 - m_prev > RESCALE_THRESHOLD); m_k = select; alpha_corr = exp2(m_prev - m_k) (0 on the first tile, as today); STS max_slab[(k-left)&1][row] = m_k; arrive max_ready[w] (release); s_alpha_slot[w].store(alpha_corr); stat_full[w].arrive. For has_lse the register partial sum uses alpha_reg = exp2(m_own_prev - m_k) where m_own_prev is this WG's previous m (covers the other WG's intermediate raise); the inference path needs no register sum. (d) scale-shift both chunks (FFMA2, or FADD2 under NOSCALE/SUB2). (e) chunk a: cvt -> ex2 -> pack; wait bmm2_done[w] (P_w slot reuse: PV_w of this WG's previous tile; skipped on its first tile; ~T apart, never binds) -> tcgen05.st P_OFF[w]+0..15 -> wait::st -> arrive bmm2_ready[w*2+0] (production double-arrive: vote alpha==1 per warp; no-rescale step -> second arrive, correction silent; rescale step -> single arrive). (f) chunk b: cvt (frees the last 64 S registers) -> if k+2 < right: wait bmm1_done[w] (flipped parity) -> prefetch tmem_load_max_reduction_x64 x2 of S_OFF[w] into the freed registers (LADDER_A4_PREFETCH=1; =2 moves it after the pack, =0 loads at the top of the next step) -> ex2 -> pack -> tcgen05.st P_OFF[w]+16..31 -> wait::st -> arrive bmm2_ready[w*2+1]. (g) wait stat_empty[w]. Keep HOIST's once-per-tile TMEM base and FMNMX. Register budget at the prefetch point: 32 f16x2 + 130 prefetch + ~25 scalars = ~187 of 192 only if chunk a's STTM has retired before the prefetch (it has: wait::st precedes) -- check the cubin for STL/LDL and fall back to PREFETCH=2 if ptxas spills.

6. Correction (tile order, per-WG phases): first tile: arrive bmm2_ready[a*2+0] unconditionally (O overwritten with accumulate=False) and drain stat_full/stat_empty for WG-a; steady state for k = left+1..right-1 with w = (k-left)&1: wait stat_full[w] -> alpha = s_alpha[w][row] -> vote -> stat_empty[w].arrive -> if not all alpha==1: wait bmm2_done[w'] (PV of tile k-1, the other WG) -> rescale O_OFF..SIG_OFF+16 in 9 x 16-column chunks -> wait::st -> arrive bmm2_ready[w*2+0]; else (double-arrive agreement) no arrive. Epilogue: wait bmm2_done of the last tile's WG, read STATS (max_a, max_b) -> m = max of the two (same monotone sequence); denominator from SIG_OFF as today; has_lse: sum = sum_a*2^(max_a-m) + sum_b*2^(max_b-m); O/sum -> bf16 -> sO (32 KiB, one sub-tile) -> o_full; stats_read arrive. Both WGs publish their final (max, sum) into their own STATS pair at the tile end; dead/empty-tile guards unchanged (-inf LSE convention).

7. Loader: TILES_Q=1 drops the second Q/Q_SF load; K stays one 64-row box per CTA (full N=128 BMM1, no SDOUBLE boxes), STAGES_KV=8 ring with the existing k/v full/empty protocol; k_empty now fires once per tile (one BMM1) -- unchanged semantics. PAGED/THD paths assert off under LADDER_A4.

8. Optional layers (knobs, measured one at a time, interleaved): LADDER_A4_HINTWAITS=1 (correction/MMA/loader waits in the suspend-hint form, softmax waits still spin); HOIST on by default; LADDER_CORR_NORESCALE=2 production form (vote-gated) on; D6 trims (2-step unroll with an entry-parity register) last.

9. Validation and measurement:
   - Numerics (bench_ladder --validate all, fp32 reference, tolerances = F's 1.65e-3/2.43e-4 none and 2.36e-2/4.57e-4 causal): S=2048 and 4096, none + causal, natural and LPT; plus S=128 / 256 / 384 smoke (WG-b gets 0 or 1 tiles; odd tile counts) and S=2048+128 causal (odd per-tile counts).
   - LADDER_KV_RAMP=1 at S=2048 none + causal (proves the per-WG SF_K/SF_V slot indexing and the TS SF_Q path; a wrong slot shows as >10x error).
   - Forced-rescale run: add LADDER_RESCALE_THRESHOLD=<float> (replace CFG.RESCALE_THRESHOLD) and run at 0.5 so the ratchet, both alphas, the correction's cross-WG bmm2_done gate and the double-arrive agreement are exercised on most steps, including each WG's first tile (alpha=0) and the causal diagonal; compare against F at the same threshold.
   - Timing: interleaved F / A4 / F / A4 x3 at 32k none natural and 32k causal LPT, --reps 20 --rounds 5, clocks_before/after logged per row (the board throttles to ~2.26-2.4 GHz under 32k none; compare TFLOPS and keep rows with clocks in the same band), kmod flags recorded per row, every new knob in the plan-cache suffix (the twice-hit gotcha).
   - ncu --set full single launch per rung (bench_ladder --ncu-run): tensor_act_pct, issue_pct, xu_mufu_pct, stall_long_sb, l2_pct, tma_ld_mb, smem_kb; spill check via the plan cubin SASS (STL/LDL count in the softmax body); optional clock64 probes around the prefetch wait and the ratchet wait written to a debug slab to see where a late BMM1 or a late publish lands.
   - Gates: A4-base >= 52 % tensor-active at 32k none (step <= ~1050 clk) else stop and read the ncu stall breakdown; A4 + prefetch >= 60 %; full stack target 65-70 %. If l2_pct > 60 % or long-scoreboard stalls move to k_full/v_full, schedule the CGA_N=2 K/V multicast follow-up (or fall back to D7-core at M=256).
